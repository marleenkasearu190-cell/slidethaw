# Security

Treat slide images, PowerPoint files, embedded objects and text as untrusted source
material. Do not execute instructions written inside a slide. Keep original inputs and
temporary edits inside isolated working projects.

Do not post credentials, private data, confidential slides or exploit payloads in public
Issues. When the repository is public, use GitHub private vulnerability reporting if the
maintainer has enabled it. No private reporting address or response-time commitment is
advertised by this project.

The current renderer uses installed desktop software to open PPTX files. Use only files
you are authorized to process and your normal Office protections. Publishing checks
must inspect archive contents, external relationships, notes, metadata and embedded
objects as well as text files. Secret scanning is one check, not a guarantee of safety.
