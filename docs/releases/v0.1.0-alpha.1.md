# SlideThaw v0.1.0-alpha.1

Initial public prerelease, prepared on 2026-10-04. This is an early integration release,
not a stable compatibility or reconstruction-quality guarantee.

## Included

- Complete existing `rebuild-ppt-image-compare` Skill, metadata version 2.2.
- One editable slide by default, with optional original/reconstruction comparison.
- Frozen content, exact bindings, scoped edits, native grouping and image exceptions.
- Original artifact-tool builder and host Presentations finalizer, unchanged.
- English/Chinese documentation, safe installation, runtime diagnosis and audit tools.
- A self-authored synthetic reference and a genuinely built, rendered and edited PPTX.

## Downloads And Installation

Release assets include `SlideThaw-v0.1.0-alpha.1.zip`, `overview_editable.pptx` and
`SHA256SUMS.txt`. The source archive contains the complete maintained Skill, tools,
documentation, tests and synthetic example. It excludes runtime libraries, private
evidence, credentials, font files and original user presentations.

Install the declared Python dependency and follow [installation](../installation.md).
Actual rebuilding additionally needs a compatible Codex host providing artifact-tool
and the Presentations finalizer. Those components are not bundled or represented as
publicly installable npm packages. Desktop acceptance needs separately installed Office software.

## Known Limits And License

Arbitrary-image unattended recognition, dense Chinese examples, native table/chart/math
adapters, broad real-slide quality and cross-platform desktop acceptance are not validated.
Small HTML-to-Office text baseline differences remain. No fidelity percentage is claimed.

The maintainer has chosen not to set a project-wide license. This release is public,
but no MIT, Apache-2.0 or other project-wide open-source license has been assigned.
External dependencies retain their own terms; see [third-party notices](../../THIRD_PARTY_NOTICES.md).
