# SlideThaw v0.1.0-alpha.1 首发说明

本页为保留的[英文首发说明](v0.1.0-alpha.1.md)的中文版本，不是新 Release。
首发准备日期为 2026-10-04，是早期集成预发布，不保证稳定兼容性或通用还原质量。
[实际 Release](https://github.com/marleenkasearu190-cell/slidethaw/releases/tag/v0.1.0-alpha.1)。

## 包含内容

- 完整既有 `rebuild-ppt-image-compare` Skill，元数据版本 2.2。
- 默认一页可编辑输出，按需原图/重建双页对照。
- 冻结内容、精确绑定、指定范围修改、原生分组与图片例外。
- 原有 artifact-tool 构建器和宿主 Presentations finalizer，未替换。
- 中英文文档、安全安装、运行时诊断与审计工具。
- 自制合成参考图，以及实际构建、渲染和编辑过的 PPTX。

## 首发实际验证

- 原始确定性测试：42 项通过；打包测试：9 项通过。
- [公共便携 CI](https://github.com/marleenkasearu190-cell/slidethaw/actions/runs/37186807382)：51 项与本地链接通过，提交 `e8b4f189c9b0ce47c85c533e6716928eb108f436`，早于后续仅文档的发布记录。
- 本地 Markdown 链接、分发审计与秘密扫描通过。
- 合成示例：8 个原生文字载体、1 个原生语义分组与1个栅格例外。
- WPS 14.0：渲染、编辑/重开与严格非目标保护通过。
- PowerPoint 16.0：渲染、编辑/重开通过；保存副本后的非目标像素严格保护失败。

详细证据与限制见[验证记录](../validation.md)。示例 PPTX SHA256：
`ec1e65267ef6b44b71332aba58736b6eedff9c3ae811a8c55f340cff4c388a27`。

## 下载与安装

首发附件为 `SlideThaw-v0.1.0-alpha.1.zip`、`overview_editable.pptx` 和 `SHA256SUMS.txt`。
源码包含完整维护的 Skill、工具、文档、测试与自制示例，不包含运行库、私密证据、凭据、字体文件或用户原始演示文稿。
按[安装说明](../installation.md)安装声明的 Python 依赖。
真正重建还需要兼容 Codex 宿主提供 artifact-tool 和 Presentations finalizer；它们不打包，也未被宣称有已验证的公共 npm 安装渠道。
桌面验收需要另行安装目标 Office 软件。

HTML 与 Office 间仍有小幅文字基线差异，不宣称还原百分比。
